## 2. Code Blocks

Các khối mã nguồn và lệnh hệ điều hành được tự động phân biệt màu cú pháp, có tiêu đề tập tin và nút **Copy** 1-chạm:

```typescript title="api-client.ts"
import type { PostMeta } from './types';

// Nạp và giải nén chỉ mục bài viết trực tiếp qua Web Stream
export async function fetchCompressedPosts(): Promise<PostMeta[]> {
  const response = await fetch('/posts.txt');
  if (!response.ok) throw new Error(`HTTP ${response.status}`);

  const ds = new DecompressionStream('gzip');
  const stream = response.body?.pipeThrough(ds);
  if (!stream) throw new Error('Không thể giải nén luồng dữ liệu');

  const text = await new Response(stream).text();
  return JSON.parse(text);
}
```

Bạn cũng có thể chèn mã lệnh trực tiếp trong dòng chữ bằng dấu backtick như `npm run dev`, `git status` hoặc `docker compose up -d`.

## 4. Tables

Bảng biểu định dạng rõ ràng, tự động hỗ trợ cuộn ngang mượt mà trên thiết bị di động:

| Đường Dẫn (Endpoint) | Giao Thức | Định Dạng Trả Về | Mô Tả Chức Năng | Chiến Lược Bộ Đệm (Cache) |
| :--- | :--- | :--- | :--- | :--- |
| `/posts.txt` | `GET` | Binary (Gzip) | Danh mục tóm tắt tất cả bài viết | Stale-While-Revalidate |
| `/posts/:id.md` | `GET` | Text (Markdown) | Nội dung chi tiết của một bài viết | In-Memory LRU Cache |
| `/tags.json` | `GET` | JSON | Danh mục nhãn và chủ đề bài viết | Lưu trữ LocalStorage |
| `/pinned.txt` | `GET` | Plain Text | Danh sách các ID bài viết ghim nổi bật | Runtime Memory Cache |

## 5. Procedural Steps

1. **Bước 1: Chuẩn bị môi trường**
   - Đảm bảo máy tính đã cài đặt phiên bản Node.js từ 20.x trở lên.

3. **Bước 3: Khởi động máy chủ phát triển**
   - Chạy lệnh `npm run dev` và mở trình duyệt tại địa chỉ `http://localhost:5173`.

<details>
<summary>Bấm vào đây để xem danh mục các plugin Markdown hỗ trợ</summary>

## 9. Hướng Dẫn So Sánh Nên & Không Nên Làm (Do's & Don'ts)

| Phương Pháp Khuyến Nghị (Nên Làm) ✅ | Hành Vi Cần Tránh (Không Nên Làm) ❌ |
| :--- | :--- |
| Nén chỉ mục dữ liệu tĩnh bằng Gzip hoặc Brotli trước khi truyền tải | Truyền tải mảng JSON thô kích thước lớn không nén qua mạng |
| Áp dụng kỹ thuật Lazy Loading cho các thành phần dựng Markdown nặng | Đóng gói toàn bộ trình phân tích Markdown vào bundle trang chủ |
| Kiểm tra và xác thực tính an toàn của URL trước khi hiển thị liên kết | Cho phép người dùng nhúng trực tiếp URL không qua lọc ranh giới |
