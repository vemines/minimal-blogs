# Hướng dẫn cấu hình IP tĩnh mạng nội bộ và thông tuyến máy chủ HIS/PACS

> [!IMPORTANT]
> Mạng nội bộ bệnh viện sử dụng dải IP tĩnh được phân bổ riêng theo từng Khoa/Phòng để đảm bảo an ninh thông tin bệnh án điện tử và kết nối máy chủ dữ liệu.

---

## 1. Thông số dải mạng bệnh viện tiêu chuẩn

| Thông số | Giá trị quy định | Ghi chú |
| :--- | :--- | :--- |
| **Subnet Mask** | `255.255.255.0` | Chuẩn lớp C cho từng tầng/khoa |
| **Default Gateway** | `192.168.1.1` | Địa chỉ Router trung tâm |
| **DNS Server 1** | `192.168.1.254` | DNS Server nội bộ viện |
| **DNS Server 2** | `8.8.8.8` | DNS dự phòng Google |

---

## 2. Các bước cấu hình IP tĩnh trên Windows

### Bước 1: Mở cài đặt Network Connections
- Bấm tổ hợp phím <kbd>Windows</kbd> + <kbd>R</kbd>.
- Nhập lệnh `ncpa.cpl` rồi bấm <kbd>Enter</kbd>.

### Bước 2: Chọn card mạng Ethernet
- Click chuột phải vào biểu tượng **Ethernet** (hoặc **Local Area Connection**).
- Chọn **Properties**.

### Bước 3: Đặt địa chỉ IP
- Nhấp đúp chuột vào dòng **Internet Protocol Version 4 (TCP/IPv4)**.
- Tích chọn **Use the following IP address** và nhập các thông số được cấp cho máy tính của bạn.

---

## 3. Kiểm tra kết nối tới Server HIS/PACS

Mở Command Prompt và chạy lệnh ping tới máy chủ hệ thống:

```powershell title="test-connection.ps1"
# Kiểm tra thông tuyến tới Server HIS
Test-Connection -ComputerName 192.168.1.10 -Count 4

# Kiểm tra thông tuyến tới Server Lưu ảnh PACS
Test-Connection -ComputerName 192.168.1.20 -Count 4
```

> [!CAUTION]
> Tuyệt đối không tự ý đặt trùng địa chỉ IP với các máy siêu âm, máy chụp X-Quang, máy CT hoặc máy chủ máy in trong khoa. Nếu thấy báo lỗi **IP Conflict**, hãy ngắt dây mạng ngay và báo cho IT.
