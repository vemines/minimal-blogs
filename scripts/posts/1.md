Bài viết này cung cấp tiêu chuẩn định dạng nội dung Markdown mẫu và các UI Component được hỗ trợ trực quan trên Minimal Blogs.

---

## 1. Thông Báo Cảnh Báo (Callouts)

Hệ thống hỗ trợ 5 kiểu cảnh báo trực quan theo chuẩn GitHub Alert:

> [!NOTE]
> **Ghi chú**: Đây là thông tin nền tảng, bối cảnh triển khai hoặc lưu ý cơ bản cần nắm.

> [!TIP]
> **Mẹo hữu ích**: Bạn chỉnh sửa dữ liệu bài viết trong file `data.json` để giữ thụt lề rõ ràng, sau đó chạy lệnh `npm run minify` để tạo ra `posts.json` siêu nhẹ.

> [!IMPORTANT]
> **Quy chuẩn ID**: Tên file bài viết phải khớp chính xác với `id` trong file `data.json` (ví dụ: bài `id: 1` tương ứng file `posts/1.md`).

---

## 2. Khối Lệnh (Code Block) & Phím Tắt

Các khối mã nguồn được làm nổi bật cú pháp và hỗ trợ nút Copy 1 chạm:

```json title="data.json"
[
  {
    "id": 1,
    "title": "Tiêu đề bài viết",
    "summary": "Tóm tắt ngắn gọn",
    "datetime": "2026-10-13 09:00:00",
    "tags": [1, 2]
  }
]
```

Sử dụng thẻ `<kbd>` cho các tổ hợp phím tắt:
- Tìm kiếm nhanh: <kbd>Ctrl</kbd> + <kbd>K</kbd>
- Chuyển giao diện sáng/tối: <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>T</kbd>
